    Настройки

    Яндекс Музыка

    Как получить токен
    1. Откройте DevTools (F12), вкладка Network, включите Preserve log.
    2. Перейдите по ссылке авторизации.
    3. В фильтре запросов введите auth? и найдите запрос auth?external-domain=music.yandex.ru…
    4. В заголовке X-Retpath-Y скопируйте значение access_token=.

    Spotify

    Как создать приложение Spotify
    1. Откройте Spotify Developer Dashboard и создайте приложение (Web API).
    2. Добавьте Redirect URI http://127.0.0.1:8888/callback — точно такой же, как в поле выше.
    3. Скопируйте Client ID и Client Secret.
