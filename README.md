# 🎵 Перенос плейлиста из Яндекс Музыки в Spotify

Этот скрипт позволяет перенести плейлист "Мне нравится" из Яндекс Музыки в Spotify.

**Протестировано и работает!** Успешно переносит 99%+ треков с умным алгоритмом поиска.

## ⚠️ Про ВПН и гео-блокировку

Яндекс Музыка блокирует доступ к аккаунту при подключении через ВПН (гео-блокировка), а Spotify
в некоторых регионах, наоборот, доступен только через ВПН. Из-за этого **нельзя подключиться
к обоим сервисам одновременно в рамках одного запуска**, если ваш регион требует ВПН для Spotify.

Поэтому перенос разбит на **два независимых шага**, между которыми нужно переключить ВПН:

1. **`fetch_yandex.py`** — получает треки из Яндекс Музыки и сохраняет их в файл
   `yandex_liked_tracks.json`. Запускается **без ВПН**.
2. **`music_transfer.py`** (или `playlist_updater.py`) — читает треки из этого файла и работает
   только со Spotify. Запускается **с ВПН** (если он нужен вам для доступа к Spotify).

Между шагами файл `yandex_liked_tracks.json` служит "чекпоинтом" — второй шаг можно перезапускать
сколько угодно раз без повторного обращения к Яндекс Музыке.

## 🚀 Установка

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Получите токен Яндекс Музыки:**
   - Откройте DevTools (инструменты разработчика) в любом браузере (F12)
   - На вкладке **Network** (Сеть):
     - В Chrome и ему подобным: найдите и поставьте галочку **Preserve log**
     - В Firefox: нажмите шестеренку и включите **непрерывный лог**
   - Перейдите по ссылке: https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
   - В поле **Filter** (Chrome) или **поиск url** (Firefox) введите: `auth?` (без кавычек)
   - Найдите запрос типа: `auth?external-domain=music.yandex.ru&overembed=no&__t=...`
   - Кликните на этот запрос
   - На вкладке **Headers**, в самом низу найдите параметр **X-Retpath-Y**
   - В этом параметре будет ссылка с вашим токеном `access_token=...`
   - Скопируйте значение токена после `access_token=`

3. **Создайте приложение Spotify:**
   - Перейдите в [Spotify Developer Dashboard](https://developer.spotify.com/dashboard/)
   - Нажмите "Create an App"
   - Заполните название и описание
   - В настройках приложения добавьте **Redirect URI**: `http://127.0.0.1:8888/callback` (Spotify не принимает localhost)
   - Скопируйте **Client ID** и **Client Secret**

## 🎯 Использование

### Шаг 1: Получение треков из Яндекс Музыки (без ВПН)
```bash
# Отключите ВПН, если он у вас включен
python fetch_yandex.py
```
Скрипт запросит токен Яндекс Музыки (если он не задан в `config.py`/переменных окружения)
и сохранит треки в `yandex_liked_tracks.json`.

### Шаг 2: Перенос в Spotify (с ВПН, если нужен)
```bash
# Включите ВПН, если он нужен вам для доступа к Spotify
python music_transfer.py
```
Полный перенос — создаёт новый плейлист со всеми треками из `yandex_liked_tracks.json`.

Либо, чтобы обновить уже существующий плейлист (добавить только новые треки):
```bash
python playlist_updater.py
```
Обновлятор позволяет:
- Выбрать существующий плейлист из списка
- Сравнить треки с сохранёнными треками из Яндекс Музыки
- Добавить только новые треки
- Создать новый плейлист, если выбранный не найден

### Пробный запуск без изменений в Spotify (`--dry-run`)
Оба скрипта поддерживают флаг `--dry-run` — треки ищутся в Spotify как обычно,
но плейлист не создаётся и не изменяется. Удобно, чтобы заранее посмотреть статистику
(сколько треков найдётся) перед реальным переносом:
```bash
python music_transfer.py --dry-run
python playlist_updater.py --dry-run
```

### Запуск с файлом конфигурации
```bash
# Шаг 1: получение треков (без ВПН)
python fetch_yandex.py

# Шаг 2: перенос (с ВПН)
python run_with_config.py

# Шаг 2 (альтернатива): обновление плейлиста (с ВПН)
python run_updater_with_config.py
```

Если вы не настроили переменные окружения, скрипт попросит ввести необходимые данные.

## 📋 Что делает скрипт

1. **`fetch_yandex.py`** подключается к Яндекс Музыке и сохраняет список всех понравившихся
   треков в `yandex_liked_tracks.json` (запускается без ВПН)
2. **`music_transfer.py` / `playlist_updater.py`** читают этот файл и ищут каждый трек в Spotify
   используя умный алгоритм поиска:
   - Поиск по точному названию трека и исполнителю
   - Поиск по приблизительному совпадению
   - Сравнение результатов для выбора наилучшего совпадения
3. Создают новый плейлист в Spotify (или обновляют существующий) с найденными треками
4. Сохраняют список ненайденных треков в файл `not_found_tracks.json`

## 📊 Результат

После выполнения вы получите:
- 📄 Файл `yandex_liked_tracks.json` со списком треков из Яндекс Музыки (чекпоинт после шага 1)
- ✅ Новый или обновлённый плейлист в Spotify с перенесенными треками
- 📄 Файл `not_found_tracks.json` со списком треков, которые не удалось найти
- 📈 Статистику переноса в консоли

## 🔧 Возможные проблемы и решения

### Яндекс Музыка не подключается / ошибка авторизации на шаге 1
- Убедитесь, что **ВПН отключен** — Яндекс Музыка блокирует доступ к аккаунту при подключении из-за рубежа
- Убедитесь, что токен скопирован полностью из параметра `X-Retpath-Y`
- Токен должен начинаться с `AQ` и быть довольно длинным
- Попробуйте получить новый токен, следуя инструкции выше
- Убедитесь, что включили **Preserve log** перед переходом по ссылке

### Spotify не подключается / ошибка авторизации на шаге 2
- Если Spotify недоступен в вашем регионе напрямую — убедитесь, что **ВПН включен**
- Проверьте корректность Client ID и Client Secret
- Убедитесь, что добавлен правильный Redirect URI
- При первом запуске браузер откроется для авторизации

### Треки не находятся в Spotify
- Некоторые треки могут отсутствовать в Spotify
- Попробуйте найти их вручную с другим названием
- Список ненайденных треков сохраняется в `not_found_tracks.json`

## 🎵 Функциональность

### Два шага, два режима
1. **`fetch_yandex.py`** — получение и сохранение треков из Яндекс Музыки (без ВПН)
2. **`music_transfer.py`** — полный перенос: создание нового плейлиста со всеми треками (с ВПН)
3. **`playlist_updater.py`** — обновление плейлиста: добавление только новых треков в существующий (с ВПН)

### Умный поиск треков
Скрипт использует несколько стратегий поиска:
- Точный поиск по названию и исполнителю
- Поиск с кавычками для точного совпадения
- Простой текстовый поиск
- Сравнение результатов по алгоритму схожести строк

### Интеллектуальное сравнение треков
Обновлятор плейлистов включает:
- Нормализацию названий треков для сравнения
- Удаление спецсимволов и лишних пробелов
- Алгоритм схожести с порогом 85%
- Точное определение дубликатов

### Ограничения API
- Соблюдение лимитов запросов к API
- Задержки между запросами для стабильной работы
- Пакетная загрузка треков в плейлист
